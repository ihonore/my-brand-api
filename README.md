# The Backend of my former portfolio website

> This is the backend-end part which was developed using the MERN (MongoDB, Express.js, React, Node.js) stack. It features a robust architecture with multiple routes to handle various functionalities, including user authentication, blogpost management, message management, content delivery and many more.

- See the live <a href="https://ihonore.netlify.app" target="_blank">portfolio website</a> for more information.
- The API documentation of this project is <a href="https://ihonore-api-deploy.herokuapp.com/api-docs/" target="_blank">here</a>.
- The frontend repository of this project is <a href="https://github.com/ihonore/my-brand" target="_blank">here</a>.
